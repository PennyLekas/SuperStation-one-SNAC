# SuperStation-one-SNAC
THIS PROJECT IS UNTESTED

An experimental SNAC breakout for the Retro Remake SuperStation one.

This peoject consists of 2 PCBs. One to break the PSX port out into a JST connector and aonther to receive the borken out PSX control lines and convert them to the USB3.0 SNAC port. 

The SNAC adapter has level shifint built in for 5V and 3.3V controllers.
